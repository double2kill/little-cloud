# ☁️ Eva's Cloud Universe — Eva 的云端宇宙

> 一个关于 Eva 的梦幻数字世界，让故事、记忆和惊喜每天都在这里发生。

**Project Status:** Idea / Planning  
**Version:** 0.1.0  
**Type:** Interactive Digital Experience

---

## 1. 项目简介

Eva's Cloud Universe 是一个以 Eva 为主题的互动数字世界。

它不只是一个粉丝应援网站，而是一个可以持续生长的虚拟宇宙。

在这里，有一座每天都会发生新故事的云朵小屋，有来自不同时间和世界的神秘来信，有记录真实瞬间的星星档案馆，也有粉丝共同留下的时光胶囊。

希望通过创意设计、前端交互、3D 场景和 AI 内容生成，创造一个有趣、温暖、充满惊喜的数字空间。

**核心理念：让每一天都有一点新故事，让每一段记忆都有自己的位置。**

## 2. 核心模块

### 2.1 ☁️ Eva's Cloud House — 云朵小屋

整个数字宇宙的入口。

一座漂浮在云端的小屋，每天都会随机发生一些有趣的小事情。

可能发生的事件：

- 云朵突然开始下雨。
- 一只陌生猫咪来到门口。
- 屋顶掉下来一颗星星。
- 窗台出现一份神秘礼物。
- 小屋收到一封没有署名的信。
- 某个角落出现了隐藏彩蛋。

**核心体验：**
- 每日随机事件。
- 可交互的场景元素。
- 隐藏彩蛋和特殊事件。
- 随时间变化的天气与环境。
- 可探索的虚拟小屋。

### 2.2 ✉️ Mysterious Letters — 神秘来信

每天收到一封来自不同世界的信。

信件来源可以是：

- 未来的 Eva。
- 平行世界的 Eva。
- 会说话的小猫。
- 一颗迷路的星星。
- 云朵小屋的神秘访客。
- 来自宇宙深处的未知信号。

信件内容可以是搞笑、治愈、浪漫或充满想象力的小故事。

**核心体验：**
- 每日随机生成信件。
- 不同角色拥有独特的表达风格。
- 特殊日期解锁特别信件。
- 收藏喜欢的信件。
- AI 辅助生成故事内容。

### 2.3 🌌 Parallel Lives — 平行人生

一个持续更新的 AI 创意短视频系列。

每一集讲述 Eva 在不同世界里的生活。

创意方向：

| 世界 | 故事设定 |
|---|---|
| 魔法世界 | Eva 是一位魔法学院学生 |
| 午夜咖啡馆 | Eva 经营一家只在午夜营业的咖啡馆 |
| 月球世界 | Eva 是月球上最后一位居民 |
| 梦境世界 | Eva 可以进入别人的梦境 |
| 未来世界 | Eva 拥有一台可以穿越时间的机器 |
| 猫咪世界 | Eva 变成了一只拥有魔法的猫咪 |

**核心体验：**
- 每集约 15 秒。
- 统一角色形象和视觉风格。
- 每集拥有独立的小故事。
- 不同故事之间可以存在隐藏联系。
- 通过 Seedance 等 AI 视频工具辅助制作。

### 2.4 ⭐ Star Archive — 星星档案馆

记录直播中的真实瞬间、经典语录和特别日期。

每一个值得收藏的瞬间，都可以变成一颗星星。

星星可以按照时间、主题或事件分类。

记录内容：

- 直播中的有趣瞬间。
- 经典语录。
- 特别的日期。
- 重要活动和纪念日。
- 粉丝共同经历的故事。

**核心功能：**
- 星空式可视化展示。
- 点击星星查看对应记忆。
- 按日期浏览历史记录。
- 特殊纪念日星星。
- 逐渐形成一片独一无二的星空。

### 2.5 🕰️ Time Capsule — 时光胶囊

一个可以让粉丝留下文字的时间胶囊。

粉丝可以写下一段祝福、一个故事，或者对未来的期待。

选择一个未来日期，将内容封存。

到了指定日期，再一起打开。

**核心功能：**
- 粉丝提交文字和祝福。
- 创建不同主题的胶囊。
- 设置开启日期。
- 倒计时展示。
- 到期后统一开启。
- 保存过去的胶囊记录。

## 3. 整体世界设计

初步设想采用一个可探索的云端小岛作为首页。

不同的场景元素对应不同的功能模块。

| 场景元素 | 对应模块 |
|---|---|
| 云朵小屋 | Cloud House |
| 门口的信箱 | Mysterious Letters |
| 天空中的传送门 | Parallel Lives |
| 夜空中的星星 | Star Archive |
| 漂浮的玻璃瓶 | Time Capsule |

用户可以通过点击场景中的物体进入对应模块。

未来可以加入：
- 漂浮的云朵。
- 动态天气。
- 星星闪烁。
- 随机出现的小动物。
- 日夜变化。
- 隐藏互动和彩蛋。

## 7. 产品设计原则

1. **持续生长：** 内容可以不断增加，而不是一次性展示完毕。
2. **轻量互动：** 不需要复杂操作，每次访问都能获得一点乐趣。
3. **真实记忆：** 档案馆中的真实事件与 AI 创作内容需要明确区分。
4. **非礼物驱动：** 不通过送礼物、消费或好感度作为核心互动机制。
5. **尊重隐私：** 粉丝投稿应支持审核、授权和隐私保护。
6. **独立价值：** 即使没有任何人主动参与，这个世界本身也应该是一个完整、有趣的作品。

## 8. 项目愿景

让一座小小的云朵小屋，慢慢变成一个完整的数字宇宙。

这里有每天发生的小故事，有来自不同世界的信件，有值得收藏的真实记忆，也有许多等待开启的时光胶囊。

**Every cloud has a story. Every star holds a memory.**

每一朵云都有自己的故事，每一颗星星都收藏着一段记忆。
